# Overview

This directory contains relevant assets for workshop session named [Flutter Basics for Web Developers: Stateless vs Stateful Widgets](https://gdg.community.dev/events/details/google-gdg-hong-kong-presents-flutter-basics-for-web-developers-stateless-vs-stateful-widgets/). Here's a manifest of files in this directory:

- `presentation-slide.pdf` - Slide used during the workshop.
- `assets.zip` - Contains fonts and images needed to complete [Bundling Local Assets into the Project](https://nbenedictcodes.com/notes/2026-08-07-gdghk-flutter-study-group#bundling-local-assets-into-the-project) section.

If you're here, feel free to head to my website containing the workshop notes ([link](https://nbenedictcodes.com/notes/2026-08-07-gdghk-flutter-study-group)).
